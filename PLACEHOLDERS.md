# Contact page placeholders

| File | Placeholder | Replace with |
|---|---|---|
| `src/pages/Contact.jsx` | `+234 000 000 0000` | The studio's real contact phone number. |
| `.env` | `VITE_EMAILJS_PUBLIC_KEY` | The EmailJS public key from the account settings. |
| `.env` | `VITE_EMAILJS_SERVICE_ID` | The EmailJS service ID for the email service. |
| `.env` | `VITE_EMAILJS_TEMPLATE_ID` | The EmailJS service template ID for the contact form template. |

The site identifies Faim Arts as based in Lagos, Nigeria, and already lists `faimarts@gmail.com`; those existing details are reused rather than replaced with placeholders.
